# examples/: runnable example projects

| Project | Shows |
|---|---|
| [demo/](demo/) | Sliding-lid box: two mating parts, clearances, color and font pickers, multi-plate output |

Each example is a complete project folder (`lib/ parts/ assembly/ scripts/*_config.sh dist/`)
built by the **root** scripts: `scripts\build.bat examples\demo`.
Independent of the root project. Delete this folder whenever you like
(`python scripts/init_project.py --drop-examples`).
